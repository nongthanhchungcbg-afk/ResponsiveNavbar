# Thanh điều hướng responsive

Bài thực hành xây dựng navbar bằng HTML, Flexbox, media queries và JavaScript.

## Chạy thử

Mở `index.html` trực tiếp trong trình duyệt. Ở màn hình rộng, các liên kết hiển thị theo hàng ngang. Ở màn hình rộng tối đa 760px, dùng nút menu để mở hoặc đóng danh sách.

Nút menu có trạng thái ARIA; menu cũng đóng khi chọn liên kết, nhấn Escape hoặc chuyển kích thước màn hình.
